# パパパラメーター mini

育児や日々の出来事を入力すると、HP/MP、基礎パラメーター、スキル、称号、図鑑が育っていくローカル保存型のミニWebアプリです。

## 使い方

1. `index.html` をブラウザで開く
2. 初期設定を入力する
3. 日々の出来事を入力して「育成する」を押す
4. レポート画面から `.papa` ファイルを書き出してバックアップする
5. 別端末やデータ消失時は `.papa` ファイルを読み込んで再開する

## 公開前メモ

- APIキーや外部AIサービスは使っていません。
- 入力データはブラウザ内に保存されます。
- GitHub Pagesで公開しても、他の人の入力内容がこちらに送られる仕組みはありません。
- `.papa` ファイルは個人のセーブデータなので、公開リポジトリには入れないでください。

## GitHub Pages向け

このフォルダの中身をGitHubのリポジトリに置けば、静的Webアプリとして公開できます。
